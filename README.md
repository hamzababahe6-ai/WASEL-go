# WASEL GO

Starter Flutter project for a navy-and-white, Arabic-first ride-hailing app for Mauritania.

## What is included
- Arabic RTL launch screen
- Customer, driver, and admin entry screens
- Starter navigation and theme
- No paid packages required for this starter

## Important
This is a working UI starter, not yet a production ride-hailing service. Live maps/GPS, phone OTP, user accounts, real-time ride matching, payments, and admin analytics require backend and map-service configuration plus testing.

## Run locally
1. Install Flutter and Android Studio.
2. Open this folder in Android Studio or VS Code.
3. Run `flutter pub get`.
4. Run `flutter run`.

To build an Android APK: `flutter build apk --release`
